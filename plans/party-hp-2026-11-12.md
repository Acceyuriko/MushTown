组队 v1（W19.1）和共享经验（W19.2）做完了。这一块做**别人头顶的队伍血条**：
官方美术 `UIParty.img/partyHP`（九宫格）就在 WZ 里。
排期不定 ✓ → 单机的主干做完再做 ✓（`plans/more-maps-2026-11-12.md` ✓ 也写了 ✓）。

## 为什么做这个

- 组队 v1 的队伍窗里有 "Show Member HP" 那一行（官方美术自带 ✓），但没功能：
  那一行现在是个**没有用的字** ✗（没有勾选框 ✓ 点它也没反应 ✓）
  → 做完这一块才有用 ✓（官方是 `check:partyHP` 那个勾选框 ✓）。
- 官方就是每个队员头顶一条血条 + 数字（HP 百分比）。

## 这周做什么

1. **客户端报告自己的血量**：新帧 `PartyHp`（客户端→服务端：int 血量百分比，33 号 ✓）。
   - 血量变化超过 5% 才发（不必每帧发 ✓）。
   - 服务端把百分比存起来（每个客户端一个数 ✓，没报过 = 100 ✓）。
   - 百分比 = `chara.Hp * 100 / Progression.BuffedMaxHp(chara.Level, OwnHpPct())`
     （`OwnHpPct()` 是加血上限的加成 ✗ 不是当前血量 ✓）。
2. **协议**：成员名单 `PartyMember` 多带一个血量百分比。
   - `PartyInfo` / `PartyPlayers` 帧的成员结构变了（客户端服务端同一份代码 ✓）。
   - 有人报血量时，服务端重发队伍名单（和等级变化一样 ✓）。
3. **客户端画血条**（`MushTown.Client/Panels/HudParty.cs` 或新文件）：
   - 导出器先把美术存出来（`ExportPartyUi.cs` ✓）：
     `UIParty.img/partyHP/{nw,ne,sw,se,n,s,w,e,c}` ✓
     和 `UIParty.img/partyHP/GaugeBar/gauge` ✓
     → 现在仓库里没有这一段 ✓（本机 assets 里的 `party_hp_*.png` 是没提交的试验品 ✗
     别人重新导出是没有的 ✓）。
   - 在每个队员的头顶画官方的九宫格血条（`UIParty.img/partyHP`：
     nw/ne/sw/se 5x7，n/s 1x7，w/e 5x5，c 1x5 ✓）。
   - 九宫格是半透明白边框（#66FFFFFF ✓），里面那条血是粉色的
     （`UIParty.img/partyHP/GaugeBar/gauge` = #FFFC3577 ✓，
     和 `partyMemeberGaugeColor` 一样 ✓）。
   - 宽度 = 血量百分比（整条 100% 的宽度进 `layouts/panel-party.json` ✓）。
   - 位置：队员头像上方（偏移量进 json ✓）。
4. **测试**（`MushTown.Tests/PartyTests.cs`）：
   - 客户端报血量 → 队伍里另一个客户端的成员名单里能看到这个百分比。
   - 不在队里的人看不到。
