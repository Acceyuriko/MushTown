## 2. 视频没直接演，但官方一定有、我们缺的

这三条是官方客户端的基础规则，视频里看不出单独的时刻，但缺了手感会明显不对：

1. **点哪个窗口，哪个到最前。**
   我们：画和点都按 `UiWindow.List` 的创建顺序（`UiWindows.cs:57/63`），点/拖一个被别的窗压住的窗口，它不会上来。
2. **Esc 一次关一层**（先关最上面的窗，再按关下一个）。
   我们：一次关全部（`MushTownGame.cs:463` 和 `:469` 两段）。
3. **物品 tooltip**：鼠标停在物品上，显示名字 + 属性。
   我们：完全没有。`ItemData` 里有 `Name / Hp / Mp / Price / Slot / Atk / Def / Str / Dex`（`GameData.cs:282`），够做 v1。

## 5. 验收标准

每条都能用一句话验：

1. 开两个窗 → 点后面那个 → 它跑到最前。
2. 开三个窗 → 按 Esc → 只关一个；再按 → 再关一个。
3. MENU 开着 → 点地面 → 窗还在，点击不吞（人物照常走）。
4. 菜单开着 → 按方向键 → 高亮在列之间走；按 Enter → 打开对应窗。
5. 鼠标停在背包里的药水上 → 出现名字和 "+50 HP"。
6. 把药水拖进第 5 格 → 按 5 → 喝掉；重进游戏还在。
7. 世界地图 → 鼠标停在目的地上 → 出说明；点 Go → 传送。
