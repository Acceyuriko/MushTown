现金商店是最后一个大 UI。它不是 NPC 商店，是一个全屏窗口。
先做装备栏 / 装饰栏，再做这里的现金商店。

## 为什么做这个

- 现在只有 NPC 商店（药店、装备店）。买不到现金道具。
- 官方现金商店的 UI 文件是 `UI/UICashShop.img`。旧版 `CashShop.img` 和 `CashShopGL.img` 不用。
- 现金道具的价格 WZ 里没有。`Item/Cash` 只有 `info/icon` 和 `info/cash = 1`，价格要自己写。
- 单机只用 meso。NX、Maple Point、Reward Point 都不做购买。
- 装备和 Cash 是两套系统。装备有属性，进装备包；Cash 只改外观，进 Cash 包。
- 显示外观优先看 Cash：Cash 有就画 Cash，Cash 没有才画游戏装备。动作也跟 Cash 武器走。
- 纸娃娃装备（有属性）目前支持 `Wp` / `Ma` / `MaPn` / `Pn` / `So` 五个槽。Cash Fashion 只改外观，不写这些槽。先只卖武器和外套两类。
- 长袍（`MaPn`）占 Top 格；Bottom 格变红锁住，不能穿下装。
- 头发和脸现在烤在 `chara/body/{action}.json` 里。要换发型和脸，必须新增可替换的纸娃娃部件。

### 两套外观

- 装备系统：`CharaSlot.Equips`（穿在身上的有属性装备）和 `CharaSlot.EquipBag`（装备包）。它决定 Atk / Def / Str / Dex 等属性。
- Cash 系统分两个包：`CharaSlot.CashBag`（非装饰现金道具）和 `CharaSlot.DecBag`（装饰现金道具）。另有 `CharaSlot.CashWorn`（正在穿的装饰 Cash 外观）。它不改属性。
- `CashWorn` 存正在穿的装饰现金道具 item id：Fashion、当前发型券、当前脸券。穿上时从 `DecBag` 扣 1 件；脱下时加回 `DecBag`。穿在身上的东西不在背包里，不能卖、不能丢。穿同槽位的新 Fashion 会顶掉旧件，旧件回 `DecBag`。`CharaSlot.Hair` / `Face` 存当前外观 id，用来画人物。
- 同一槽位同时有装备和 Cash 外观时，画 Cash 外观，不画装备外观。属性仍只算装备。
- 武器动作也按外观武器：
  - 有 Cash 武器就按 Cash 武器的 `info/attack` 选攻击动作。
  - 没有 Cash 武器就按装备武器。
  - 都没有就用初学者动作。
- `ItemData` 新增 `public int Attack { get; set; }`，从 WZ `info/attack` 导出。
- 攻击动作映射：`1 → swingO1`、`2 → swingT1`、`3 → swingP1`、`4 → stabO1`、`5 → stabT1`、`6 → shoot1`，其他值先用 `swingO1`。
- 武器动作要使用的动作集必须导出到 `assets/chara/body/{action}.json`，并且 `Net.Actions` 要认识这些动作。
- 长袍特例：`ItemSlot` 是 `MaPn` 的道具占 Top 格，Bottom 格变红锁住，不能穿下装；双击 Top 格脱整件长袍。
- CASH 页显示 `CashBag` 的非装饰道具（Utility / Convenience）。
- DEC 页显示 `DecBag` 的装饰道具（Fashion、头发、脸）。
- 两个页都用格子位置：`CashOrder` / `DecOrder`，规则和装备栏 / 装饰栏计划的背包格子一样。空位、拖放、整理键都适用。
- 装备包只放有属性的装备。Cash / Dec 道具永远不进装备包。

### 存档

装备栏 / 装饰栏计划里已经加好这些字段，现金商店直接复用：

```csharp
public bool Female { get; set; } // false = male, true = female
public int Hair { get; set; } // current hair cosmetic id
public int Face { get; set; } // current face cosmetic id
public Dictionary<int, int>? CashBag { get; set; } // non-decorative itemId -> count (CASH tab)
public Dictionary<int, int>? DecBag { get; set; } // decorative itemId -> count (DEC tab)
public List<int>? CashWorn { get; set; } // worn decorative item ids: Fashion, current hair coupon, current face coupon
public List<int>? CashOrder { get; set; } // CASH tab cells: item id, 0 = empty
public List<int>? DecOrder { get; set; } // DEC tab cells: item id, 0 = empty
```

- 男默认头发 `5157257`、男默认脸 `5158151`；女默认头发 `5157258`、女默认脸 `5158152`。四个都白送；当前性别的两件穿在 `CashWorn`，另外两件放在 `DecBag`。
- 旧存档不迁移：缺少四个 order list（或长度不是 128）的旧档直接删档重建。
- 买发型/脸以后写真实 cosmetic id，并 `SaveChara()`。
- 载入时校验：`Hair` / `Face` 必须在 `Hairs` / `Faces` 清单里（包括默认条目）。不在就报错。
- 载入时校验：`CashWorn` 里的 id 只能是三类：Fashion（`ItemData.Slot` 不为 null）、`Hairs` 的 ItemId、`Faces` 的 ItemId。`DecBag` 里同 id 的剩余件数可以大于 0（买了重复件）。

### 现金背包（CASH / DEC 页）

- 官方背包有 6 个页签，第 5 个（下标 4）是 Cash，第 6 个（下标 5）是 Dec。
- `HudInventory` 的 `TabCount = 6` 不变，`i == 4` 和 `i == 5` 都注册点击。
- CASH 页列 `CharaSlot.CashBag` 的非装饰道具，按 `CashOrder` 的格子位置显示。
- DEC 页列 `CharaSlot.DecBag` 的装饰道具，按 `DecOrder` 的格子位置显示。
- 两个页的空格子都能拖放；整理键只整理当前页签，规则和 Equip / Use 一样。
- 格子和别的页签一样，用现有的 `PanelSlot`。
- DEC 页双击 Fashion：穿上 / 脱下 Cash 外观，写 `CashWorn`。
- DEC 页双击头发/脸：换成这个发型/脸，写 `Hair` / `Face`。
- CASH 页 Utility 双击使用对应效果，详见下一节。所有道具都有图标、数量、tooltip。
- 新角色创建时四个默认条目都要有：当前性别的两个默认券在 `CashWorn`，另一个性别的两个默认券在 `DecBag`。新存档不因为玩家卖掉默认券又自动补回来。

### Utility 道具的使用

- 这里的 SP 是技能点，不是属性点。属性 STR / DEX / INT / LUK 按升级自动加，没有属性点分配，所以不做 AP 重置。
- `Character Name Change`：
  - 双击弹输入框，复用 `Basic.img/sysPop` 的 INPUT 模式。
  - 名字规则和创建角色一样：长度、字符、全存档唯一。
  - 成功：改 `CharaSlot.Name`，刷新 HUD 名字，扣 1 个道具，存档。
  - 失败：弹提示，不扣道具。
- `SP Reset Scroll`：
  - 双击弹确认框。
  - 确认后把所有技能等级清零，按 `SkillSpCost = 1` 退回总 SP。
  - 成功：扣 1 个道具，存档。
  - 没有已学技能：提示 `You have no skills to reset.`，不扣道具。
- `Gender Change Coupon`：
  - 双击弹 `wm_pop` Yes / No 确认框。
  - 确认后 `Female` 取反，头发 / 脸换成新性别的默认款。
  - 当前穿着的旧发型券、旧脸券从 `CashWorn` 移回 `DecBag`；新性别默认券从 `DecBag` 移到 `CashWorn`。背包没有新性别默认券时先补一张（免费）。
  - 已买的头发、脸、Fashion 都留在 `DecBag`，不删。
  - 成功：扣 1 个道具，存档。
  - 取消：不扣道具。

## 通用掉落改动（做现金商店时一起做）

### 玩家丢弃

- 触发、数量框、扣背包的规则见 `plans/equipment-2026-12-03.md` 的「背包修改 / 丢弃」。
- 单机：本地 `MobWorld` 直接生成掉落，走现有的 `DrainDrops` → `ApplyDropSpawn`。
- 联机：新增 `Net.DropItem`（client → server：int itemId, int count）。服务器用该玩家最后一次 `State` 的 map / x / y 生成掉落，再广播 `DropSpawn`。
- `MobWorld` 增加 `DropItem(map, x, y, kind, id, count)`，使用和怪物掉落同一套 `GroundDrop` 和 `_fresh`。
- 地上一个掉落只占一个 uid，数量为 count 件；捡一次全拿走。
- 捡起时按道具种类放回包：普通装备 → `EquipBag`，普通消耗品 → `Use`，非装饰现金道具 → `CashBag`，装饰现金道具 → `DecBag`。现金 / 装饰包要同时补 `CashOrder` / `DecOrder` 的格子。

### 怪物多件掉落摆放

- 一次击杀的 payout 先全部收集，再统一算位置。`MobWorld` 按 item id 缓存从 `assets/item/{id}.json` 读到的 `IconW`。
- `ItemData` 增加 `IconW`（导出时写 `info/icon` PNG 的宽度）。图标宽度从 `ItemData.IconW` 读；meso 固定按 24 算。
- 多件按 payout 顺序从左到右排成一行，整行以怪物 x 为中点。
- 每件之间留 0px。整行放不下时先整体平移进地图 VR 边界。
- 整行比地图还宽：每件 x 在 VR 内随机，允许重叠。
- 每件 y = 该 x 下方最近的地面。
- `DropTable.Roll` 不再返回 dx，改由 `MobWorld` 统一摆。

### 掉落物动画

- `DropArt` 增加 `FromX`、`FromY`、`SpawnMs`、`State`、`Rotation`、`BobPhase`。`State` 分 `Falling` / `Resting` / `Taken`。
- `DrawDrop` 用图标中心作原点，按 `Rotation` 旋转；上下浮动加在 y 上。
- `MobWorld.Drop` 增加 `FromX` / `FromY`。怪物掉落的来源是怪物中心；玩家丢弃的来源是玩家脚下。
- `Net.DropSpawn` 增加 `fromX` / `fromY` 两个 float；`NetClient` 的解析长度一起改。`DropTake` 不变，拾取动画用 taker id 找当前坐标。
- 出生：图标从来源向上弹出，同时旋转，约 0.4 秒落到目标点。
- 落地：停止旋转，图标上下浮动 ±2px。
- 拾取：图标从地面向上飞进拾取者身上，约 200ms 后消失。`DropTake` 的 taker 为 0 表示过期，直接消失，不播拾取动画。
- 晚进图的玩家看到地上的掉落直接显示在落点，不播出生动画。

- 只把目标 img 的部件写进输出帧。身体、头、默认脸、默认头发只用来算骨头。
- 输出：
  - `assets/chara/hair/{cosmetic:D8}/{action}.json`
  - `assets/chara/face/{cosmetic:D8}/{action}.json`
- 图片和 json 同目录。
- 头发文件是 `Hair/{cosmetic:D8}.img`（例 `Hair/00065370.img`）。
- 脸文件是 `Face/{cosmetic:D8}.img`（例 `Face/00020053.img`）。
- 每个动作的帧数必须和身体一样，否则报错。
- 脸在背向帧可以没有部件。这种空帧允许，客户端不画。
- `Panel` 命令加 `cashshop`：`dotnet run --project MushTown.Exporter -- panel cashshop`。

- Beauty：面板、标题、卡片起点、纸娃娃脚底、价格位置。
- CHECK OUT：弹框位置、道具行、图标、名字、价格、三个按钮。

## 测试

- `CashShopTests`：
  - 买 Utility 钱刚好够 → 成功，钱变 0，`CashBag` 多 count 件，`DecBag` 和 `EquipBag` 不变。
  - 买 Fashion 钱刚好够 → 成功，`DecBag` 多一件，`CashBag` 和 `EquipBag` 不变。
  - `Buy` 钱少 1 → 失败，钱和两个包都不变。
  - `BuyHair` / `BuyFace` 扣钱，`DecBag` 多一件，不改 `Hair` / `Face` / `CashWorn`。
  - 钱不够时 `BuyHair` / `BuyFace` 不加背包，不改字段。
  - 穿 Cash Fashion：`DecBag` 少一件，`CashWorn` 多一件；脱下反向。同槽位新件顶掉旧件，旧件回 `DecBag`。
  - 换头发 / 脸：新券从 `DecBag` 出，旧券回 `DecBag`，`Hair` / `Face` 更新。
  - 拾取 Cash / Dec 掉落 → 回到 `CashBag` / `DecBag`，对应 order 多一格。
  - 卖 Cash / Dec → 钱增加，对应包和 order 少掉；买回放回原包。
  - 新角色默认条目：`Female=false` → `Hair=30020`、`Face=20000`、`CashWorn` 有男默认两件、`DecBag` 有女默认两件。
  - `CashOrder` / `DecOrder` 为空 → `DecBag` 的两个默认条目补到前两格；拖动和整理后数量不变、道具不丢。
  - Character Name Change：正常改名扣 1 个；重名或非法名字不扣。
  - SP Reset Scroll：清空 `SkillLv` 并退回总 SP，扣 1 个；没有已学技能时不扣。
  - Gender Change Coupon：男→女→男都能切；每次切完头发/脸是新性别默认款，`DecBag` 的已买道具不丢，扣 1 个。
- NPC 商店滚动：
  - 左列表 12 行时滚到底，第一行是第 3 行；滚轮一格 3 行会被夹到最底。
  - Sell / Buy Back 各记各的滚动位置；右背包 6 个页签各记各的。
  - 卖掉 3 行后列表变短，滚动位置自动夹回，不出现全空。
- 联机外观：
  - `Net.Appearance` 编码 / 解码后 `Female` / `Hair` / `Face` / `CashWorn` / `Equips` 不变。
  - 外观先到、State 后到 → 新建 PeerArt 时外观已经在。
  - 远程装备 id 本地没有美术 → 该部位按没装备画，不崩。
- 启动校验测试：
  - 存档 `Hair` / `Face` 不在清单 → 报错。
  - `cashshop.json` 普通条目价格 0、数量 0、未知 Group/Tab → 报错。
  - `Hairs` / `Faces` 缺 `DefaultMale` 或 `DefaultFemale`，或默认条目价格不是 0 → 报错。
- 截图：
  - 上面 10 张 `--screen` 都要能出图。
  - 肉眼看：列表不压顶栏，不压底部导航；卡片不重叠；预览人物站在地面上；CHECK OUT 居中。
