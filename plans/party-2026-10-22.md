# 组队 v1（2026-10-22 这一周）

主干（W1..W18 + 官方 UI 大周）都做完了。这周开第一条分支：**组队**。

参考：bwiki 的冒险岛系统页（maplestorywiki.net 502 维护中，打不开）、WZ 里的官方美术
`UI/UIParty.img`（现代客户端的组队窗）。

## 为什么先做组队

- 这是冒险岛最核心的联机玩法，游戏的定位就是"局域网内和朋友联机"。
- WZ 里官方美术齐全：`UIParty.img/mainUI`（窗体 + 页签 + 三个按钮 + 成员行
  模板 + "没有队伍"提示层）、`UIParty.img/partyHP`（队伍血条九宫格）、
  聊天窗的 party 页签（`StatusBar3.img/chat/.../chatTarget/party`）。
- 队友之间的共享经验是这条分支的"游戏性回报"，放到下一周（W19.2）。

## 这周做什么（W19.1）

1. **服务端队伍状态**（新文件 `MushTown.Server/World/PartyWorld.cs`）
   - 队伍 id → 成员 id 列表（队长在第一位），成员 id → 队伍 id。
   - 建队 / 邀请 / 接受 / 拒绝 / 离开 / 踢人（v1 不做踢人）。
   - 队长走了，队自动解散（v1 简化：不解散，自动推下一个当队长）。
2. **协议**（`MushTown.Shared/Net/Net.cs` 加消息号）
   - `PartyMake`（客户端→服务端）、`PartyInvite`（目标 id）、
     `PartyAsk`（服务端→被邀请的人：谁邀请的）、`PartyAnswer`（接受/拒绝）、
     `PartyInfo`（服务端→队员：成员名单 id+名字+等级）、
     `PartyLeave`、`PartyChat`（只在队内转发）。
3. **客户端组队窗**（新文件 `MushTown.Client/Panels/HudParty.cs`）
   - 官方美术：窗体、页签、建队/邀请/退队按钮、成员行（名字/等级/队长皇冠/在线图标）、
     "没有队伍"提示层。
   - 成员行文字位置用 WZ 的 `entity/pos` 官方坐标，**所有数字进
     `layouts/panel-party.json`**（本仓规矩：定位数字进 json，美术尺寸留代码）。
4. **邀请流程**：点"邀请"→ 官方搜索页签列出**本图的其他玩家** → 点行上的
   `btInvite` 发邀请 → 对方弹出邀请框 → 接受/拒绝。
   - 只有队长能邀请（官方规则：队长皇冠 + 邀请按钮的 disabled 状态图）。
     队长走了自动推下一个当队长。
   - 邀请框用官方的对话框（`UI/UIWindow2.img/UtilDlgEx` + BtYes/BtNo 按钮）：
     519 宽的官方对话框，名字在上面的页签里，BtYes/BtNo 在下面的蓝条里。
     WZ 里的 `UIWindow2.img/UserList/PopupInvite` 其实是"按名字邀请"的表单
     （INVITE BY NAME / RECOMMENDED PARTY MEMBERS），不是收到邀请时弹的框。
   - 搜索窗用官方 `UIParty.img/mainUI/searchWnd`（Find Field Party 那一页
     就是"本图的玩家" ✓）。列表框位置用 WZ 的 `vector:subWnd_lt`。
5. **队伍聊天**：聊天输入行左边加官方的聊天目标按钮
   （`StatusBar3.img/chat/ingame/input/chatTarget/party` = "To Party"，
   `.../chatTarget/all` = "To All"）。点它切换：文字只发到队内。
   官方聊天日志页签只有 All/Etc（这个 WZ 里没有 Party 页签图），
   队内的话在 All 页签里显示。
6. **入口**：组队窗用快捷键 P 打开（设置页里可改，官方键位图标 19 = PARTY）。
   官方 MENU 里没有组队项（只有活动链接），所以不进 MENU。

## 这周不做什么

- 共享经验、队伍血条（画在别人头顶）、跟随队友换频道、公会、好友、交易。
- 队伍名编辑（WZ 有 `edit:partyName`，v1 用固定名）。
- 邀请弹窗不是模态的：弹窗开着的时候可以走开、可以换图，答案也不看图
  （还在同一张图才让邀请生效这件事以后再做）。
- 没有服务器时组队窗里不画"建队"按钮（点了没反应就是死按钮，违反项目规则）。

## 验收

- 单机开房 + 另一个客户端加入同一张图 → 两边都能看到对方。
- A 点"建队" → A 的组队窗出现 A（队长皇冠）。
- A 点"邀请" → 搜索页签列出 B → 点邀请 → B 弹出邀请框 → B 接受 →
  两边的组队窗都出现两个人。
- 队伍聊天页签：队内的话两边都看得到，非队员看不到。
- 退队按钮 → 窗回到"没有队伍"。
- 门禁：format 净 + build 0 错 + 测试全过（测试工程只引用 Shared/Server，
  队伍逻辑放 Shared 的话能测）。
- 审完提交（每块一个 commit）。
