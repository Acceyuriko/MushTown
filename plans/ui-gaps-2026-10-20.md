## 1. 现在和视频差什么（要做的）

视频是 1920×1080 的现代 GMSR 客户端。我们内部固定 1366×768 渲染再整幅放大（AGENTS.md 红线），所以**尺寸不同是正常的**，不用改。

按"缺什么"排：

### 步骤 1 —— 真 MENU 窗（UITotalMenu）
现在：HUD 上一个深色小弹层，5 行白字（Character Info / Inventory / Quest / Settings / Exit）。
要改成：视频 440s 那个大 MENU 窗。
- 底图 `UITotalMenu.img/main/backgrnd` 1022×698
- 7 列页签，页签名在底图里
- 菜单项按钮：`menu/buttonInfo/<col>/<row>/{normal,pressed,disabled,mouseOver}/0`（136×40）。**图标和文字都烤在 PNG 里**，客户端只画 PNG，不再画字也不叠图标
- `main/key/<id>`（16×16）不是菜单图标，是键帽小徽章（步骤 2 之后再说）
- 底排 7 个按钮：`button:cashShop` `button:mapleAuction` `button:channelChange` `button:characterSwitching` `button:keySetting` `button:option` `button:gameQuit`（各 136×40）
- 右上关闭 `button:close`（20×20）
- 只有我们真有的功能可点（Character Info / Inventory / Quest / World Map / Skills / Key Bindings / Settings / Exit），其余画成 disabled 态
- 点 Key Bindings 开键窗（现在键窗只能从设置窗进）
- 数字全进 `layouts/panel-menu.json`

步骤 1 做完（W1）还差的（不影响验收，先记着）：
- 每行右边的**键帽小徽章**（视频里 Character Info 右边是 "V" 那种）：官方 `main/key/<id>` 是默认键的图，我们要画"当前绑定"的徽章，得自己画。
- 右上角**频道名**（`main/vector:info` = 894,16 + `font:info`）：蓝药丸在图里，文字要客户端画，但我们还没有频道名数据。
- 官方窗是**磨砂玻璃**（`main/sprite:base` + shader + 背后模糊屏），我们没有模糊 → 白板只能烤不透明。
- 官方只在**快捷栏编辑模式**下画 `main/layer:editModeGuide`（那条 "Drag menu icons into the Quick Menu for easy use." 药丸）。普通菜单不画 ✓ 我们现在也是不画。

### 步骤 2 —— QUICK MENU 条（UITotalMenu/quickMenu）
视频 440s 底下的 "QUICK MENU" 灰条 + 视频 165s 底排那排图标。
- 55 个图标 `UITotalMenu.img/quickMenu/menu/<i>/{normal,pressed,disabled,mouseOver}`（每个 30×30，Tooltip 已有官方文字）
- 背景 `quickMenu/backgrnd` 33×35 + `interval` 33
- 放在屏幕底部，玩家拖图标进格子（编辑模式）
- v1 简化：**先做静态展示 + 点击打开对应面板**，不做拖拽编辑
- **灰条本体烤在 `main/backgrnd` 画布底部**（x 259..762, y 616..696，11 个空格子）→ W2 把它从画布里单独抠出来，当**常驻 HUD**画在屏幕底部（官方位置 `main/vector:quickMenuPos` = 277,648，`quickMenu/interval` = 33），不能只跟着 MENU 窗一起出现。

## 3. 工作方式

- 一周一步。每步做完停下给用户看。
- 每步一个 worker 写代码，一个一次性干净 subagent 审查（不带历史结论）。
- 审查发现 P0/P1/P2 全修。修完再跑一次审查直到干净。
- 门禁：`dotnet format MushTown.sln --exclude WzComparerR2` 净 + build 0 错 0 警告 + 全部测试过。
- **提交前必须用户同意。**
- 数字进 `layouts/panel-*.json`，美术尺寸留代码里。

## 4. 美术导出

每个面板一个导出器文件（跟现有 `ExportKeyUi.cs` 一个写法）：

```sh
dotnet run --project MushTown.Exporter -- panel menu [OutDir]
```

导出到 `assets/ui/menu_*.png`。`assets/` 不进 git。
